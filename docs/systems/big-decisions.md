# Task 26: ตัดสินใจครั้งใหญ่ (ซื้อบ้าน/รถ) + พบผู้คน

> สถานะ: ✅ **Implemented** — 2026-11-16 (ใช้ตัวเลือกที่แนะนำ ผู้ใช้ทักท้วงได้)

## 1. สรุปความเข้าใจ
- **ซื้อบ้าน/รถ:** หน้าเลือกซื้อบ้าน (คอนโด ทาวน์เฮาส์ บ้านเดี่ยว บ้านหรู) และยานพาหนะ (มอเตอร์ไซค์ รถเล็ก รถครอบครัว รถหรู) จ่ายเงินสดหรือผ่อนกับธนาคาร เห็นเงินดาวน์ ค่างวด ดอกเบี้ย และเหตุผลที่ไม่อนุมัติก่อนกด
- **มีคนเข้ามาตีสนิท:** เหตุการณ์ให้ตอบรับ/ปฏิเสธ ตอบรับ = ได้เพื่อนใหม่
- **เพศตรงข้ามเข้ามาให้รู้จัก → คบ → แต่งงาน → มีลูก:** เหตุการณ์สำหรับคนโสด ตอบรับ = ได้คนรู้จักเพศตรงข้าม (ชวนเดท/ขอแต่งงาน/มีลูกต่อได้ในแท็บ People ซึ่งมีอยู่แล้ว) หรือเสี่ยงชวนเดทเลย (สำเร็จ = เป็นแฟน) · ทุกคนมีอวตารตามเพศและอายุ (ข้อ 27)

## 2. การตัดสินใจ
| หัวข้อ | การตัดสินใจ | เหตุผล |
|---|---|---|
| รายการของซื้อ | content ใหม่ `purchases.json`: `{ id, nameKey, descKey, category: home/vehicle, assetId, price, loanProduct, effects }` ราคาเป็นมูลค่าจริง (แสดงตามยุค) · ซื้อแล้วเป็นสินทรัพย์ในพอร์ต (มูลค่าขึ้นลงตามตลาด ขายได้ในหน้าลงทุน) | ใช้ระบบสินทรัพย์ + สินเชื่อเดิม (`FinanceService.BuyWithLoan`) |
| สินทรัพย์ใหม่ | ทาวน์เฮาส์ (1.8 ล้านขึ้นไป), บ้านหรู (8 ล้าน+), มอเตอร์ไซค์ (30,000+), รถครอบครัว (8 แสน+), รถหรู (2.5 ล้าน+) | ให้ราคาของแต่ละรายการถูกกับขั้นต่ำของสินทรัพย์ |
| ราคา | คอนโด 1.5 ล้าน · ทาวน์เฮาส์ 2.5 ล้าน · บ้านเดี่ยว 4.5 ล้าน · บ้านหรู 12 ล้าน · มอเตอร์ไซค์ 55,000 · รถเล็ก 550,000 · รถครอบครัว 1.1 ล้าน · รถหรู 4 ล้าน | ราคาไทยโดยประมาณ ปรับได้ใน content |
| วิธีจ่าย | เงินสด (ต้องมีพอ) หรือผ่อน: บ้าน = สินเชื่อบ้าน (ดาวน์ 10% 30 ปี) รถ = สินเชื่อรถ (ดาวน์ 15% 6 ปี) ใช้การอนุมัติเดิม (อายุ เครดิต รายได้ ล้มละลาย) | ไม่สร้างกติกาสินเชื่อซ้ำ |
| ใครซื้อได้ | ผู้ใหญ่ (อายุพึ่งพาตัวเอง 18+) | เด็กไม่ซื้อบ้าน |
| ผลของการซื้อ | Effect ของรายการ (Strategy เดิม): ความสุข/ความเครียด + Flag `life.adult.first_home` (บ้าน) / `life.young.first_car` (รถ) → **เหตุการณ์ชีวิต [64] กู้ซื้อบ้าน และ [35] ซื้อรถคันแรกจะไม่เกิดซ้ำ** (เงื่อนไข "ยังไม่มี Flag") และพลังแฝงต่อเนื่องของมันทำงาน | เหตุการณ์กับการกระทำจริงไม่ขัดกัน |
| เจ้าของบ้าน | มีบ้าน/คอนโดในพอร์ต → ค่าใช้จ่ายรายเดือนตามระดับชีวิตลด 25% (`finance_settings.homeOwnerLivingDiscount`) | ไม่ต้องเช่า |
| Undo | การซื้อสร้าง Checkpoint เหมือนการตัดสินใจอื่น | |
| พบคนเพศตรงข้าม | Effect `meet` เพิ่ม `"sex": "opposite"` · ใช้กับเหตุการณ์ใหม่ และแก้ [38] เจอคู่ชีวิตในมหาลัย / [79] รักครั้งใหม่ ให้เป็นเพศตรงข้าม (เดิมสุ่มเพศ) | ตามที่ผู้ใช้ขอ |
| เหตุการณ์ "มีคนเข้ามาตีสนิท" | `social.approach_friend` อายุ 10+ น้ำหนัก 4 เว้น 2 ปี สูงสุด 8 ครั้ง/ชีวิต: รับ = เพื่อนใหม่ + ความเหงาลด / ปฏิเสธ = เครียดลดเล็กน้อย | |
| เหตุการณ์ "มีคนเข้ามาทำความรู้จัก" | `social.approach_romance` อายุ 18–60 ต้องโสด น้ำหนัก 4 เว้น 1.5 ปี: (1) คุยทำความรู้จัก = คนรู้จักเพศตรงข้าม (ชวนเดทได้ในแท็บ People) (2) ชวนเดทเลย โอกาส 50% = เป็นแฟน / ไม่สำเร็จ = ความมั่นใจลด (3) ปฏิเสธ | คบ → แต่งงาน → มีลูก ใช้ Interaction เดิม |
| เข้าถึงหน้าซื้อ | แท็บการเงิน ปุ่ม "ซื้อบ้าน / รถ" | |

## 3. JSON
```jsonc
// content/purchases.json
{ "purchases": [ { "id": "home.condo", "nameKey": "purchase.home.condo.name", "descKey": "purchase.home.condo.desc", "category": "home",
    "assetId": "condo_city", "price": 1500000, "loanProduct": "mortgage",
    "effects": [ { "type": "flag.set", "flag": "life.adult.first_home" }, { "type": "stat", "stat": "mental.happiness", "amount": 10 } ] } ] }
// effect meet
{ "type": "meet", "relation": "contact", "chance": 1, "sex": "opposite" }
// finance_settings.json
"homeOwnerLivingDiscount": 0.25
```
