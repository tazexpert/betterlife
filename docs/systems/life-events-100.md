# Task 22: 100 เหตุการณ์สำคัญในชีวิต + บทปฐมบท (อายุ 3+) ตามแบบของผู้ใช้

> สถานะ: 🟡 **ชุดที่ 1/4 Implemented** — 2026-11-16 (กลไก + บทที่ 1 อายุ 13–18 จำนวน 30 เหตุการณ์ + บทปฐมบท อายุ 3–12 จำนวน 20 เหตุการณ์ที่ผู้ใช้เพิ่ม) · ชุดที่ 2–4 (บทที่ 2–4) ทำใน Session ถัดไป

## 1. สรุปความเข้าใจ
ผู้ใช้ออกแบบ 100 เหตุการณ์ แบ่ง 4 บทตามช่วงอายุ (13–18, 19–25, 26–45, 46–70+) แต่ละเหตุการณ์มี
- **โอกาสเกิด** (เช่น 25%) = โอกาสที่เหตุการณ์นี้จะเกิด **หนึ่งครั้ง** ภายในช่วงอายุของบทนั้น
- **พลังแฝง** = เมื่อเกิดแล้ว ทำให้เหตุการณ์อื่นในอนาคตมีโอกาสมากขึ้น/น้อยลง (เช่น +15% โอกาสเกิด [3]) และผลทันทีต่อค่าต่างๆ (เช่น −10% สุขภาพ)
- บางเหตุการณ์ "ตาม[55]" = เกิดตามหลังเหตุการณ์อื่น

## 2. การตัดสินใจ (ใช้ตัวเลือกที่แนะนำ — ผู้ใช้ทักท้วงได้)
| หัวข้อ | การตัดสินใจ | เหตุผล |
|---|---|---|
| ชนิดเหตุการณ์ใหม่ | `"trigger": "milestone"` + `"milestone": { "minAge": 13, "maxAge": 18, "chance": 25, "modifiers": [...] }` ไม่อยู่ในการสุ่มรายสัปดาห์ปกติ (15%) แต่มีการทอยของตัวเองทุกสัปดาห์ เกิดได้ครั้งเดียวต่อชีวิต | โอกาส 25% ต้องหมายถึง "ตลอดช่วงวัย" ไม่ใช่ต่อสัปดาห์ |
| แปลงโอกาสเป็นรายสัปดาห์ | p ต่อสัปดาห์ = 1 − (1 − P)^(1/W) โดย W = จำนวนสัปดาห์ในช่วงอายุ ถ้าอยู่ครบช่วง โอกาสรวมจะเท่ากับ P พอดี; P = 100% → เกิดสัปดาห์แรกที่เข้าเงื่อนไข | ตรงตามตัวเลขที่ผู้ใช้กำหนด |
| พลังแฝง | ตีความเป็น **บวก/ลบเป็นจุดเปอร์เซ็นต์** (25% + 15 = 40%) จำกัด 0–100% · เหตุการณ์ต้นทางตั้ง Flag `life.<id>` แล้วเหตุการณ์ปลายทางมี `modifiers: [ { condition: flag, add: 15 } ]` | ตาราง "+100% โอกาสเกิด [63]" มีความหมายเมื่อเป็นจุดเปอร์เซ็นต์ |
| ผลทันที | แปลงเป็น effect ที่มีอยู่: สุขภาพ → ความฟิต/ภาระโรค, ความมั่นใจ/ความสุข/ความเครียด/ความเหงา, เงินสด, ชื่อเสียง (โรงเรียน), อบายมุข (ติดเกม → `binge_entertainment`, ดื่ม → `drinking`), อาการป่วย, พบคนใหม่ (`meet`), ทักษะ | ใช้ระบบเดิม ไม่สร้างตัวเลขลอยๆ |
| เงื่อนไขตามเหตุผล | เพิ่มเงื่อนไขที่ตารางไม่ได้เขียนแต่จำเป็น: อกหัก [13] ต้องเคยมีความรัก ([9] หรือ [19]), เลิกรา [30] ต้องเคยมีความรักจริงจัง [19], โดดเรียน [6] และเกรดตก [15] ต้องกำลังเรียน | ไม่ให้เกิดเรื่องที่ขัดกับสถานะจริง |
| แบบประกาศ | บทที่ 1 เป็นเหตุการณ์ "เกิดขึ้นแล้ว" (ไม่มีตัวเลือก) แสดงเป็น Toast/ข่าว เรื่องใหญ่ (รางวัลระดับประเทศ อุบัติเหตุ ป่วยหนัก ย้ายโรงเรียน) เป็น Major → หยุดเวลา | ตารางเขียนเป็นผลลัพธ์ ไม่ใช่ทางเลือก |
| ทับซ้อนกับระบบเดิม (บทที่ 3–4) | [55]/[63]/[65] แต่งงาน-มีลูก, [52] ตกงาน, [46] ได้งาน, [31] สอบติด, [80] พ่อแม่เสีย, [91] เกษียณ, [100] เสียชีวิต มีระบบจริงอยู่แล้ว → จะทำเป็น **เหตุการณ์ที่ผูกกับสถานะจริง** (เช่น [80] ใช้การเสียชีวิตของ NPC พ่อแม่ ไม่สุ่มซ้ำ) ตัดสินใจรายละเอียดตอนทำชุดที่ 3–4 | ไม่ให้ข้อความกับสถานะในเกมขัดกัน |
| id | `teen.<ชื่อ>` (บท 1), `kid.<ชื่อ>` (ปฐมบท K1–K20), Flag `life.<id>` | อ่านง่ายกว่าเลข |
| ช่วงอายุปฐมบท | แต่ละเหตุการณ์มีช่วงของตัวเองตามความหมาย (ทั้งบทคือ 3–12): ติว ป.1 4–6, สอบติด/ไม่ติด ป.1 6–7, เรียนพิเศษ/หัวหน้าห้อง/ดาวเด่น/ลอกข้อสอบ/เพื่อนคู่แข่ง 6–12 (ลอกข้อสอบต้องกำลังเรียน), เกม 7–12, Gifted 9–12 (ต้องกำลังเรียน), เริ่มต้นไม่สวย/หย่าร้าง 3–8, สมาธิสั้น 5–12 นอกนั้น 3–12 หรือ 4–12 | โอกาสรวมยังเท่าที่ผู้ใช้ตั้ง เพียงกระจายในช่วงที่สมเหตุผล |
| K2 / K3 | สอบติดและสอบไม่ติดโรงเรียนดังเกิดได้อย่างใดอย่างหนึ่ง (เงื่อนไข `not flag`) | ขัดกันเอง |
| K20 "[8] หรือ [26]" | ตีความเป็น +20 ให้ทั้งสองเหตุการณ์ | ไม่มีกลไก "อย่างใดอย่างหนึ่ง" ในพลังแฝง |
| ผลทันทีปฐมบท | ภาษาอังกฤษ (K5) → ทักษะ `english` +20, ติดเกม (K16) → อบายมุข `binge_entertainment`, เพื่อนคู่แข่ง (K15) → ได้เพื่อนใหม่แน่นอน (`meet` 100%), ลอกข้อสอบ (K17) → ความสัมพันธ์กับพ่อแม่ −8 และชื่อเสียงโรงเรียน −8, ป่วยเพราะเครียด (K14) → ภาระโรค +5 ความฟิต −5 | |
| เหตุการณ์ของเด็ก | ทุกอันในปฐมบทไม่มีตัวเลือก (เป็นสิ่งที่เกิดขึ้นกับเด็ก) จึงไม่ติดกฎ `minDecisionAge` | เด็กอายุ 3–5 ไม่ควรต้องตัดสินใจ |

## 6. Tests
- `MilestoneTests` (5): สูตรรายสัปดาห์ให้โอกาสรวม 25% ±1.5 (จำลอง 20,000 ชีวิต), 100% เกิดสัปดาห์แรกและครั้งเดียว, นอกช่วงอายุไม่เกิด, Modifier +100 จาก Flag, ไม่อยู่ในการสุ่มรายสัปดาห์ปกติ
- `LifeMilestoneSimulationTests` (content จริง 80 ชีวิต): ทุกเหตุการณ์ที่ไม่มีเงื่อนไขและตั้งไว้ ≥ 25% ต้องเกิดจริง > ครึ่งหนึ่งของค่าที่ตั้ง
  - **ปฐมบท (ถึงอายุ 13):** 20 เหตุการณ์ครบ, ไม่มีชีวิตไหนทั้งสอบติดและไม่ติด ป.1 · ผล: ถูกเปรียบเทียบ 60→60%, ติว ป.1 40→40%, Gifted 20→20%, สมาธิสั้น 10→10%, สอบติด ป.1 25→41% (+30 จากติว ป.1), หัวหน้าห้อง 25→34%, ย้ายบ้าน 15→24%, เครียดจนป่วย 25→16%, พ่อแม่ทะเลาะ 30→23% (ความผันผวนจาก 80 ชีวิต)
  - **บทที่ 1 (ถึงอายุ 19) หลังเพิ่มปฐมบท:** ติวสายเรียน 40→68%, ติดเกม 35→67% (+30 จากมีมือถือ +30 จากค้นพบเกม), โรงเรียนดัง 25→45%, พรสวรรค์ 30→47%, ถูกแกล้ง 15→24% — **ข้อ 21 ต้องพิจารณาว่าพลังแฝงซ้อนกันสูงเกินไปหรือไม่**
  - ผลก่อนเพิ่มปฐมบท (ตั้งไว้ → เกิดจริง)
  - ใกล้ค่าที่ตั้ง: อุบัติเหตุ 10→10%, ถูกแกล้ง 15→15%, มือถือ 50→47%, ช่วงเปลี่ยนวัย 45→42%, แก๊งเพื่อนตาย 40→41%, พรสวรรค์ 30→33%
  - สูงขึ้นเพราะพลังแฝง: ติดเกม 35→54% (+30 จากมีมือถือ), เริ่มลงทุนเร็ว 15→28% (+30 จากมีมือถือ), Glow up 25→37% (+20 จากช่วงเปลี่ยนวัย)
  - ต่ำลงเพราะเงื่อนไข: เลิกกันก่อนมหาลัย 25→9% (ต้องมีรักจริงจัง ~42%), อกหัก 30→17% (ต้องเคยมีความรัก), เกรดตก 15→5% และโดดเรียน 25→14% (ต้องกำลังเรียน + พลังแฝงลบ)
