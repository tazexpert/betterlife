# เหตุการณ์สุ่ม 30 แบบตามที่ผู้ใช้ออกแบบ (RE-01 – RE-30) — ส่วนหนึ่งของข้อ 22

> สถานะ: ✅ **Implemented** — 2026-11-16 (ใช้ตัวเลือกที่แนะนำ ผู้ใช้ทักท้วงได้)

## 1. สรุปความเข้าใจ
เหตุการณ์สุ่มที่ต้องตัดสินใจ 30 แบบ แบ่ง 3 ช่วงวัย (13–25, 26–50, 51–100) แต่ละแบบมี 2 ทางเลือก พร้อมผลทันทีและ "อนาคต" (โอกาสเกิดผลตามมา หรือเหตุการณ์ต่อเนื่อง)

## 2. การตัดสินใจ
| หัวข้อ | การตัดสินใจ | เหตุผล |
|---|---|---|
| ไฟล์ / id | `content/events/life_random.json`, id `re.<ชื่อ>` (RE-01 = `re.injured_stray` ...) | |
| "โอกาส X%" ของผลตามมา | ใช้ `chance` ของทางเลือก: สำเร็จ = ผลดี/ไม่เกิดอะไร, ล้มเหลว = ผลเสีย เช่น RE-02 ไปเที่ยว โอกาส 30% โดนจับ → ทางเลือกมี chance 70 | กลไกเดิม ผู้เล่นเห็น % ก่อนเลือก |
| "อนาคต" ที่เกิดทีหลัง | `event.schedule` เหตุการณ์ต่อเนื่อง 14 แบบ (เช่น ตำรวจตามเจอ 4–12 สัปดาห์, เงินหายเกลี้ยงบัญชี 1 สัปดาห์, เบาหวานถามหา 1–5 ปี) | "ล็อกคิว" ตามที่ผู้ใช้เขียน |
| Popup ของผลตามมา | เหตุการณ์ต่อเนื่อง (`scheduled`) หยุดเวลาและเปิด Story popup เหมือนเหตุการณ์ชีวิต | ผู้เล่นต้องเห็นผลของการตัดสินใจ |
| ค่าตัวเลข | ค่า stat และเงินตามที่ผู้ใช้กำหนด (เงินเป็นบาทตามมูลค่าจริง) · "ศีลธรรม ±X" → กรรมดี/ชั่ว ÷ 4 (สเกลกรรมของเกมเล็กกว่า เช่น ทำบุญงานวัด = 6) · "สุขภาพ ±" → ภาระโรค/ความฟิต · "เวลา −X ชม." → ความเหนื่อย · "สติปัญญา" → ความรู้ทันคน (เรื่องมิจฉาชีพ) หรือความมุ่งมั่น · "วินัยการเงิน" → เครดิตสกอร์ + ความมุ่งมั่น · "ความสัมพันธ์เครือญาติ" → ชื่อเสียงในครอบครัว | ใช้ค่าที่ระบบมีจริง |
| มิจฉาชีพ | RE-14 / RE-25 ใช้ `scam.loss` (ฟิชชิ่ง / แก๊งคอลเซ็นเตอร์) จึงอยู่ในประวัติถูกหลอกและแจ้งความได้ | ต่อกับระบบข้อ 13b |
| ทางเลือกที่ใช้เงินก้อน | ให้ยืม 20,000 / คอร์ส 15,000 / ทุนหลาน 500,000 ล็อกถ้าเงินสดไม่พอ · รูดบัตรซื้อของ (RE-06) จ่ายเกินเงินสดได้ = เป็นหนี้ | สมเหตุผล |
| เงื่อนไข | โดดเรียน/งาน ต้องเรียนหรือทำงาน, หัวหน้าฮันเตอร์/คอร์ส ต้องมีงาน, แฟนเก่าทัก ต้องมีแฟนเก่า, ลืมวันครบรอบ ต้องมีแฟน/คู่สมรส, หลาน/ลูกชวนเที่ยว ต้องมีลูก, มรดกวุ่นวาย ต้องมีลูก ≥ 2 อายุ 65+, สัตว์เลี้ยงป่วย ต้องเคยรับเลี้ยง (RE-01) หรืออายุ 51+ | ไม่ให้เกิดเรื่องขัดกับสถานะ |
| ความถี่ | น้ำหนัก 5 (ไวรัล 3), เว้นอย่างน้อย 3 ปีต่อแบบ เกิดซ้ำได้ตลอดช่วงวัย ยกเว้นเรื่องที่ควรเกิดครั้งเดียว (รับเลี้ยงสัตว์ เก็บมือถือ แมวมอง แอบชอบ ไวรัล เด็กหลง คอร์ส ผลตรวจ ทุนหลาน สัตว์ป่วย เที่ยวญี่ปุ่น มรดก) | กันการวนซ้ำที่ผู้ใช้พบ |
| เหตุการณ์เดิมที่ไม่มีขีดจำกัด | ปาร์ตี้ ทุก 52 สัปดาห์ สูงสุด 10 ครั้ง, ไข้หวัด ทุก 104 สูงสุด 15, โอที ทุก 52 สูงสุด 15, ชวนลงทุนแชร์ลูกโซ่ ทุก 104 สูงสุด 5 | จำลองพบว่าเมื่อเหตุการณ์อื่นหมดโควตา 4 แบบนี้กินสัดส่วน 79% (ปาร์ตี้ 60 ครั้ง/ชีวิต) |
| ทางเลือกเริ่มต้น (หมดเวลาตอบ) | ทางที่ปลอดภัยกว่า เช่น ปฏิเสธ / โทรเช็คธนาคาร | |
| สิ่งที่ยังทำไม่ได้ (บันทึกไว้) | รายจ่ายประจำค่าเลี้ยงสัตว์, รายได้ +40% จากการย้ายงาน (ใช้โบนัสแรกเข้า 30,000 แทน), สายอาชีพ Influencer/บันเทิง (เก็บเป็น Flag `life.re.influencer`, `life.re.showbiz`, `life.re.no_showbiz`), ยานอนหลับเป็นอบายมุข, Life Score ตอนจบ (ใช้คำไว้อาลัยแทน), ครอบครัวฟ้องกันหลังตาย (คำไว้อาลัย) | ต้องมีระบบใหม่ เสนอทำในข้อ 26 หรือหลังข้อ 22 |
| คำไว้อาลัย | Flag ที่ขึ้นใน Life Summary: รับเลี้ยงสัตว์จรจัด, เคยเป็นคนดังออนไลน์, ไปญี่ปุ่นกับลูก, ทำพินัยกรรม / ไม่ทำพินัยกรรม | แทน "Life Score" และ "หลังคุณจากไป" |
| พลังแฝงข้ามระบบ | RE-07 ตัดใจ → +15 จุด โอกาสเจอคู่ชีวิต [38] · RE-18 ได้แรงบันดาลใจ → เตรียมให้ [67] เปิดบริษัท (ชุดที่ 3) · RE-22 ปวดเข่า → เตรียมให้ [95]/[96] (ชุดที่ 4) | |
