# Task 17b: Player Actions (Life plan, Work, Invest & Borrow, Quit habits)

> สถานะ: ✅ **Implemented** — 2026-11-15 (ผู้ใช้ขอเพิ่มต่อจากข้อ 17 ใช้ตัวเลือกที่แนะนำ)

## 1. สรุปความเข้าใจ
- เติม Core loop ที่ยังขาด: **จัดเวลา 168 ชม./สัปดาห์** (แท็บ Life) พร้อมผลต่อค่าต่างๆ ต่อสัปดาห์ และ **วิธีเลิกอบายมุข**
- **แท็บ Work:** สถานะการเรียน/งานปัจจุบัน, สมัครเรียน (โอกาสสอบติด ค่าเทอม ทุน), ลาออกจากโรงเรียน, สมัครงาน (โอกาส เงินเดือนเริ่มต้น), ลาออกจากงาน
- **ลงทุนและกู้เงิน** (เปิดจากแท็บ Money): ซื้อ/ขายสินทรัพย์, กู้เงิน, เปิดบัตรเครดิต, ปิดหนี้
- ทุกการกระทำแสดงตัวเลขก่อนตัดสินใจ (โอกาส ค่าใช้จ่าย เหตุผลที่ทำไม่ได้) และแสดงผลลัพธ์หลังทำ

## 2. การตัดสินใจ (ใช้ตัวเลือกที่แนะนำ)
| หัวข้อ | การตัดสินใจ | เหตุผล |
|---|---|---|
| ปรับชั่วโมง | ปุ่ม −5 / −1 / +1 / +5 ต่อกิจกรรม ชั่วโมงที่เหลือไปที่กิจกรรมหลัก (`free_time`) อัตโนมัติตามกฎของ `TimeBudget` | ใช้นิ้วเดียวได้ ไม่ต้องพิมพ์ตัวเลข |
| ชั่วโมงเรียน/งาน | **ล็อก** (ระบบการศึกษา/อาชีพจองให้ตาม `WeeklyHours`) แสดงเป็นแถวที่แก้ไม่ได้ | ป้องกันการโดดเรียน/งานแบบไม่มีผล ซึ่งระบบยังไม่รองรับ |
| ผลต่อสัปดาห์ | ต่อกิจกรรม: ค่า stat ที่เปลี่ยน (`ActivityStatEffect.TotalFor`) ค่าใช้จ่าย/สัปดาห์ และปัญหาของแผน (`TimeBudget.Validate`) | Pillar "อ่านตัวเลขได้ทุกตัว" (ยังไม่รวมตัวคูณการเรียนรู้/ความเหนื่อย ซึ่งคำนวณตอนจบสัปดาห์) |
| ตรวจเงื่อนไขกิจกรรม | ใช้ `RuleContext` กับ `Pcg32` แยกต่างหาก (seed คงที่) | ไม่ไปแตะ Random stream ของชีวิต เซฟจึงยังเหมือนเดิมทุกไบต์ |
| Undo | ทุกการกระทำผ่าน `DecisionService` (Checkpoint ก่อน) **ยกเว้นการปรับชั่วโมง** ซึ่งปรับกลับเองได้ | ไม่ให้การกด +1 ทับ Snapshot ของการตัดสินใจจริง |
| สมัครเรียน | แสดงเฉพาะที่สมัครได้ตอนนี้ เรียงตามระดับ ถ้ายังพึ่งพาครอบครัว = ครอบครัวจ่าย ถ้าพึ่งตัวเอง = จ่ายเงินสด หรือ กยศ. (ถ้ามีค่าเทอม) | `TuitionFunding` มีอยู่แล้ว |
| สมัครงาน | แสดงสาขาที่สมัครได้ (เงื่อนไขผ่าน) เรียงตามเงินเดือนเริ่มต้น สาขาที่ไม่ผ่านซ่อน | รายการไม่ยาวเกิน |
| ซื้อสินทรัพย์ | ปุ่มจำนวนเงิน 10% / 25% / 50% / 100% ของเงินสด (แสดงเฉพาะที่ ≥ ขั้นต่ำ) | ใช้ได้ทุกช่วงเงิน ไม่ต้องพิมพ์ |
| ขาย | ขายครึ่งหนึ่ง / ขายทั้งหมด แสดงค่าธรรมเนียม | |
| กู้เงิน | ไม่แสดง **หนี้นอกระบบ** (เป็นวงเงินสำรองที่ระบบดึงใช้อัตโนมัติเมื่อเงินไม่พอ) และ กยศ. (มากับการสมัครเรียน) สินเชื่อไม่มีหลักประกัน: ปุ่มจำนวน 10,000 / 50,000 / 200,000 บาท (มูลค่าจริง แสดงเป็นราคาตามยุค) พร้อมผลการพิจารณา (`LoanQuote`) บัตรเครดิต: เปิดวงเงิน สินเชื่อบ้าน/รถ (ต้องซื้อพร้อมสินทรัพย์) **ยังไม่ทำ** | ฟอร์มซื้อพร้อมกู้ต้องเลือกราคา/เงินดาวน์ ควรทำพร้อมปรับสมดุลข้อ 21 |
| ปิดหนี้ | จ่ายงวดนี้ (`MonthlyPayment`) หรือปิดทั้งหมด (ไม่เกินเงินสด) | |
| ธุรกรรมการเงิน | ทำได้เมื่ออายุถึงเกณฑ์พึ่งพาตัวเอง (`FinanceService.IsAdult`) | ตรงกับกฎเดิมของ FinanceService |
| เลิกอบายมุข | ในแท็บ Life ส่วน "นิสัยที่ติด": ทุกวิธีที่ใช้กับอบายมุขนั้นได้ + ค่าใช้จ่าย + ระยะเวลา + เหตุผลที่ทำไม่ได้ | |
